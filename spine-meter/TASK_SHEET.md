# Task sheet: three-page site (Gauntlet, Batch, Live theatre)

Status values: TODO, DOING, REVIEW, DONE, BLOCKED.
Every task is small: one owner, one or two output files, one acceptance check.
Owners are Haiku 5.5 subagents at high effort. The coordinator checks each output before marking DONE.

## Rules every task follows

- Code must be readable by a beginner: clear names, short functions, a one-line doc comment on each function, comments only where the reason is not obvious, lines at most 120 characters.
- No paid API calls during build or tests. No git commits. Everything stays inside the project folder.
- The project's API key (in `.env`) must never appear in anything under `site/`, in logs, or in test output.
- Model replies are untrusted text. Render them as text (never as HTML).
- Python code in `core.py`, `adaptive.py`, `flows.py` and `grade.py` is the reference. JavaScript ports must match it on the fixtures in `js-tests/fixtures/`.
- The design follows `site/design/DESIGN.md` once T01 is DONE.
